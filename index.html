Configure API Key

This tool uses the OpenWeatherMap API. A key with One Call 3.0 access gets hourly forecasts; a plain free key falls back to the 3-hourly forecast automatically.

⚠

The key is saved in plain text in this browser's local storage, and each request sends it in the URL, so it can appear in server logs and browser history. Use a key you are willing to expose, and remove it when you are done.
